# miRNA-analysis

### Steps for DEA
1. Install & Load Packages 📦 --> Install BiocManager, edgeR & multiMiR
2. Load Data 📂 --> Gene Expression Data
3. Preprocess Data 🔬 --> Normalization and Summarization
4. Estimate Dispersion 📉  --> Estimate Common, Trended, Tagwise Dispersion
5. Fit GLM Model 📊 --> Fit GLM for Strain/Batch Effect
6. Perform DEG Analysis 📈 --> Get Top Differentially Expressed miRNAs
7. Retrieve Validated Targets 🎯 --> Using multiMiR for Target Genes
8. Analyze miRNA-Target Interactions 🔍 --> Check for Luciferase & Validation
9. Drug-Disease Association 💊 --> Find miRNA-Target Associations with Cisplatin
10. Predict miRNA Targets 🧬 --> Select miRNAs Predicted to Target Genes
11. Find Most Targeting miRNA 🔬 --> Identify miRNA Targeting Maximum Genes
12. Summarize & Interpret Results 📑 --> Final Results & Analysis]
